## Selected validation evidence

The v5 validation materials identify run `RUN_20261121_115035_apsens_v5_patched_audit`. The lab report records 2,230 real measured recordings across HUST, University of Ottawa, XJTU-SY and MAFAULDA. Of these, 1,951 MAFAULDA recordings are quarantined from the CC BY 4.0 commercial training pool. The reported run lists zero synthetic rows and five of five hard-stop QA gates passing.

These are **lab-reported results**, not independent personal claims of model development or validation. Consult the report and metrics directly for scope, conditions and detailed results.

MAFAULDA is explicitly kept separate from the CC BY 4.0 commercial training/checkpoint pool in the reported validation package. Do not use quarantined data commercially unless separate rights clearance authorizes it. Check each dataset's source terms and attribution obligations before reuse.

This public portfolio excludes proprietary source code, model weights and restricted raw datasets. The source manifest is retained as a checksum record for the listed upstream release artifacts; it is not a checksum of the CV or files edited specifically for this personal portfolio.
